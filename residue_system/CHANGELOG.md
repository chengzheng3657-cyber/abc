# 代码检查记录
本次检查针对上一版可运行原型，保留HTTP `/v1` 接口和二进制协议，内部文件与函数采用常见工程命名。
| 问题 | 修改 |
|---|---|
| 内部名称直接沿用算法文档术语 | 改为sampling、fitting、wire、repository等职责命名 |
| 多个采样点可能具有相同8位响应 | 在搜索候选集中去除重复响应 |
| 标定仅最小化对数强度残差 | 对数初值后加入强度域最小二乘修正 |
| 求解边界与实际标准品范围不一致 | 持久化标准品浓度上下界并用于拟合 |
| 边界截断值可能被当作有效浓度 | 范围边界返回无效状态和明确原因 |
| 单变量计算叠加两种优化步骤 | 改为直接执行有界标量最小化 |
| SQLite上下文未显式关闭连接 | 统一连接上下文，事务结束后关闭连接 |
| 报文先到后可能关联另一份原图 | 保存事务内交叉检查报文摘要并回滚冲突 |
| 同名标定可能忽略输入证据变化 | 配置和标准品数据一起执行不可变检查 |
| HTTP非法输入与业务冲突混用400 | 区分400、404、409及存储故障 |
| JSON允许重复字段或非有限数值 | 拒绝重复字段、NaN、Infinity及非法数值 |
| 启动依赖中文日志解析 | 运行器直接获取实际监听端口并管理关闭 |
| 单线程HTTP阻塞健康请求 | 有界HTTP工作线程与独立计算锁 |
| 同目录旧数据库可能带入不完整配置 | 显式数据库版本和旧库加载保护 |
新增或扩充验证覆盖：HTTP完整流程、重复请求、并发重试、标定数据冲突、原图与报文到达顺序、数据库重新加载、越界浓度、坏图像、坏CRC、非法JSON、图像映射、数值梯度和事务回滚。
运行记录证明本版本可执行及相应测试结果；模拟样本、真实标准品和历史研发证据是不同资料，代码整理不改变其来源。
